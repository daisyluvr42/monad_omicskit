# 轻量检查节点（已获用户确认）

目标：在分析前、工具返回后、交付前三个自然节点核对输入语义、实际执行和报告依据。复用输入核验记录、参数与 CLI JSON；不增加审批表、工作流引擎或针对公开数据集的预期答案。

实施范围：

1. Skill：把三个节点写进入口；按需查方法说明。改动过的提取脚本需在独立目录复现矩阵与元数据；已核验且未改变的材料不重复转换。报告只核对影响结论的事实，没有证据时保留 ID 或缩小结论。
2. 输入边界：拒绝重复/空 ID、非有限数值、遗漏的样本注释；差异模型检查缺失协变量、混杂及无剩余自由度，返回实际使用与排除的样本和两组拟合范围。
3. 注释：差异分析可显式传 species/id_type，生成有数据库版本的映射表及明确可用的 symbol；未映射或歧义不猜测。复用相同映射逻辑改正富集的 ENTREZID 接收数冒充映射数问题。
4. 富集：核对候选与背景关系，返回有效注释覆盖、无方向 ORA 的解释边界；无显著结果仍可正常交付。
5. 验收：覆盖错误输入被拒绝、顺序变化不改变结果、映射有依据、有效覆盖与检验分母一致、零显著正常通过。保留现有统计回归测试，构建并隔离安装后测试真实 CLI。

实施顺序：输入/注释与模型返回 → 富集返回 → Skill 与参数说明 → 通用回归 → 版本、打包、GitHub 与本机同步。

边界：程序证明明确的数据和计算断言，不能自动证明原始材料真实或所有生物学解释正确。最终文字与来源的核对仍由宿主按 Skill 执行，发布时明确这一验证范围。
